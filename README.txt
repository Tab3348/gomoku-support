Standalone static support website for 猫咪五子棋 / Kitty Gomoku. No game source, backend, packages, keys or signing assets. Publish the root of main with GitHub Pages; use the HTTPS github.io URL returned by Settings > Pages. Only zh-Hans, en and vi are enabled; legal content remains a review draft. Edit content.js for translations. Other language options are reserved but disabled. No custom domain required.

Product names are managed by ui.productName in content.js (Chinese, English and Vietnamese). App Store listing names and any official filing must be maintained separately; this website does not certify filing approval.
